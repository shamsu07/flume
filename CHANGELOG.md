# Changelog

All notable changes to Flume are documented here. The project follows Semantic
Versioning while its public `/v1` API remains stable.

## 0.2.0 - Unreleased

- Add deterministic, tokenizer-pinned context packs and tenant-scoped `/v1` APIs.
- Add pooled async proxying, bounded caches, health-aware affinity, and safe SSE.
- Add offline proxy/GPU benchmark harnesses and machine-readable baseline results.
- Add readiness/liveness probes, Prometheus metrics, hardened containers, and CI.

## 0.1.0

- Initial context compiler, SQLite store, vLLM proxy, SDK, and CLI.
